# LC 80：有序数组里每个数最多留两次

## 0. 问题重述

给你一个已经排好序的数组。不能另开一个结果数组；要把该保留的元素留在原数组前面，并返回这段有效前缀的长度。相同数字可以留两次，第三次及以后必须移走。

## 1. 暴力解法推导

你说“完全想不出暴力解法从哪里下手”，很正常：`删除重复项` 听起来像一句话，但“原地删除”没有真正的删除按钮。最自然的尝试是从左到右数每个值出现了几次；数到第三次时，就把这个位置后面的所有元素都向左搬一格。

一开始也许会想“数完次数再统一删除”。但统一删除仍然要处理数组中间的空洞，而且每删一个位置，右边元素都得保持顺序地搬过来。于是得到一个能工作的暴力法：扫描数组，遇到第三个相同值就执行一次左移删除。

## 2. 暴力解法的代价

例如 `[1,1,1,1,1,2]` 中第三个 `1` 要让后面 3 个元素左移，删完后还有一个多余 `1`，又要让后面 2 个元素左移。只为处理这几个重复项就搬了 5 次；若前面有很多重复项，反复搬移会累积成接近 `n²` 次操作。

## 3. 优化的关键洞察

暴力法浪费在“已经确认保留的前缀”被反复搬动。数组有序意味着相同值一定连在一起，所以不必全局计数：当准备把当前值写到 `write` 时，只要看有效前缀中 `write - 2` 的值。

如果当前值等于它，写进去就会形成第三次；如果不同，写进去最多是这个值的第二次。这样不删除任何位置，只让 `read` 读候选值、让 `write` 写保留值，一次扫描即可完成。

## 4. 最优解法讲解

可视化中 `read` 指向正在判断的候选值，`write` 指向刚写入的位置；蓝色窗口是已经确认的有效前缀。前两个元素无需比较，之后每帧的说明都会展示 `nums[write-2]` 与当前候选值的比较。

看到相等时，`read` 前进而 `write` 不扩张，表示第三次出现被跳过；看到不等时，当前值被写到有效前缀末尾。最终只读取 `nums[0:返回长度]`。

## 5. 代码实现

页面下方的 Python 与 C++ 都使用同一条规则：`write < 2` 时直接写，否则比较 `nums[read]` 与 `nums[write - 2]`。这正是生成当前轨迹的真实算法。

## 6. 复杂度总结与变体

时间复杂度是 `O(n)`，额外空间是 `O(1)`。若题目改成“每个值最多保留 `k` 次”，把 `2` 改为 `k`，并比较 `write - k` 即可。
